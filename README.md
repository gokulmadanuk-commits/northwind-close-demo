# Northwind close demo

Demo site for "From inbox to accounts": a year-end close of a fictional PE-backed company, done with Claude.

- Walkthrough slides, live dashboard and statements, EBITDA adjustments and year-end journals
- Prompt pack, sample data pack and answer key in `downloads/`

Everything here is fictional. This is a static site with no build step, and Vercel deploys it from the `main` branch.
